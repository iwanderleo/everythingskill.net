# EverythingSkill.net

**Everything can be distilled into a Skill.**

EverythingSkill is an open-source directory for discovering AI `.skill` files — structured prompt files that distill a person's thinking patterns, knowledge system, and communication style into a format AI can understand and simulate.

[everythingskill.net](https://everythingskill.net) · [中文版](README_zh.md) · [MIT License](LICENSE)

---

![EverythingSkill preview](public/og-image.png)

## What is a `.skill` file?

A `.skill` file is a plain-text AI prompt file. Think of it as an AI "personality plugin" — install a Skill, and the AI will think and respond in that person's unique style.

- Compatible with Claude, ChatGPT, Cursor, and more
- Plain text, hosted on GitHub
- Open-source, modifiable, shareable

## What EverythingSkill does

The `.skill` ecosystem is scattered across personal repos, trending threads, and community lists. EverythingSkill gives those skills a proper home:

- **Discover** — browse by category, search by name, or sort by trending and newest
- **Understand** — every skill has a curated summary, category, and rendered README from the source repo
- **Navigate** — clean bilingual pages in English and Chinese

## Submit a Skill

Found a great `.skill` file that isn't in the directory yet?

**Option 1 — Web form (easiest):**  
Go to [everythingskill.net/submit](https://everythingskill.net/submit), fill in the form, and it will open a pre-filled GitHub Issue for you.

**Option 2 — GitHub Issue directly:**  
[Open a Submit Issue](https://github.com/iwanderleo/everythingskill.net/issues/new?template=submit-skill.yml) with the structured template.

**Option 3 — Pull Request:**  
Edit [`app/data/skills.json`](app/data/skills.json) directly and open a PR. See [CONTRIBUTING.md](CONTRIBUTING.md) for the field schema.

## Automation

This directory is kept fresh automatically:

| Job | Schedule | What it does |
|---|---|---|
| Daily Sync | Every day 02:00 UTC | Fetches GitHub star counts; checks all repos for 404 (auto-archives unavailable Skills, auto-restores recovered ones); regenerates README files |
| Weekly Scan | Every Monday 03:00 UTC | Scans [awesome-persona-distill-skills](https://github.com/xixu-me/awesome-persona-distill-skills) for repos not yet in the directory — writes candidates to `missing-skills.generated.json` |

All state changes (archive / restore) are logged to [`app/data/skill-status-log.json`](app/data/skill-status-log.json).
